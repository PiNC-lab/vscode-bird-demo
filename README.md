# vscode-bird-demo

Demo project for the [VS Code for R users](https://pinc-lab.github.io/lab-manual/tutorials/vscode.html) tutorial in the PiNC Lab Manual.

Bird counts at six fynbos sites, three restored and three unrestored, each visited four times. The data are synthetic.

| File | What it is |
|---|---|
| `data/bird_counts.csv` | One row per site visit. One visit has no count |
| `analysis.ipynb` | Notebook that loads the data, summarises it and plots the mean count per site |
| `analysis.py` | The same analysis as a script. Run it with `python analysis.py` |
| `utils.py` | Functions used by both |

Follow the tutorial to fork and clone this repository and set up a Python environment to run it.
